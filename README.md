# 📝 My First To-Do List App

Ek simple aur beautiful To-Do List application jo aapko productive rehne mein madad karega!

## 🎯 Features

- ✅ Tasks add kar sakte ho
- ✅ Tasks ko complete mark kar sakte ho
- ✅ Completed tasks ko undo kar sakte ho
- ✅ Tasks delete kar sakte ho
- 🎨 Beautiful gradient UI
- 📱 Mobile-friendly design

## 🚀 How to Use

1. **Download ya clone karo yeh repository**
2. **Folder mein `index.html` open karo browser mein**
3. **Task type karo aur "Add Task" button click karo**
4. **"✓ Done" button se task complete karo**
5. **"🗑 Delete" button se task remove karo**
